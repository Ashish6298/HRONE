2. PHASE 2.2 — VALIDATION, MODELS & SERIALIZATION HELPERS
----------------------------------------------------------------------
- Implemented strict Pydantic models aligning with openapi.yaml:
  * EmployeeCreate (pattern validations for `emp_code`, email, `shift_start`, `shift_end`, `joined_on`, and distinct shift start/end).
  * PunchInRequest & PunchOutRequest.
  * RegularizeRequest.
- Implemented `validate_epoch_millis`: strictly validates integer epoch milliseconds; explicitly rejects boolean values (subclass of int), floats, string numbers, seconds-like values (< 10^11), and out-of-range timestamps.
- Implemented `truncate_to_seconds`: truncates instant microsecond precision before calculation and persistence.
- Implemented `round_half_up`: Decimal ROUND_HALF_UP rounding ensuring exact R8 and R4 mathematical accuracy (replaces built-in banker's rounding).
- Implemented `serialize_doc`: centralized response sanitizer omitting MongoDB `_id` and synthetic `id`, converting BSON datetime objects to integer epoch milliseconds, and providing safe defaults for legacy missing fields (`half_day: False`, `history: []`).
