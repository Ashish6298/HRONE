1. PHASE 4.1 — SHARED SHIFT/TIME CALCULATIONS (R1-R5)
----------------------------------------------------------------------
- Used `ZoneInfo("Asia/Kolkata")` for all calendar and shift interpretations and UTC for persisted instants.
- Implemented `get_attendance_date_from_punch_in`: accurately maps instant to IST calendar date, properly attributing overnight shifts (`shift_end <= shift_start` with punch-in < `shift_end`) to the previous calendar day.
- Implemented `compute_late_minutes` (R2): strictly enforces grace period of 10:00 (> 10 minutes late from `shift_start`), flooring elapsed minutes to whole numbers.

- Implemented `compute_work_hours` (R4): `(punch_out - punch_in) / 3600` rounded using `ROUND_HALF_UP` to 2 decimal places.
- Implemented `compute_half_day` (R5): returns True if `work_hours < 4.50`, otherwise False.
